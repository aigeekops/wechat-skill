# 微信消息

输入：联系人或群、准确正文及附件、发送或草稿模式。多人发送需要明确名单；“发到一个群”和“逐个发给多人”有歧义时先澄清。

1. 从聊天列表或微信搜索找到目标，核对标题及可用身份信息。同名或名称不符时不猜测。
2. 按 [输入](../references/input.md) 准备正文。图片、视频、文件使用当前聊天的附件入口；需要先放进手机相册时读 [媒体传输](../references/media.md)。
3. 提交前核对目标、正文、附件。媒体预览可能有独立发送按钮；正文与附件不能合并提交时按用户要求的顺序分别发送并核对。
4. 草稿模式到此停止。已要求发送时点击明确发送入口一次。iPhone 微信文字聊天实测 Return 可发送，但不能推广到其他编辑器。
5. 确认目标聊天出现本次新增正文或附件气泡，文字输入框清空，未见失败标识。超时先观察，结果不明不重新发送。

逐人发送时记录每人的“已确认发送 / 未确认 / 未处理”；恢复任务先检查已提交项目。不扩大名单或创建群聊。

实测：单人文字、文件传输助手图片发送。普通聊天图片、视频、文件、群聊和逐人发送尚无本项目完整实测记录，应按当前界面验证。
