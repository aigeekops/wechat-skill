# 朋友圈

入口：微信“发现” → “朋友圈”。从当前页面逐级返回即可，不重复启动应用。

## 查看与总结

按用户指定条数、对象或时间范围浏览，需要移动时读 [滚动](../references/scroll.md)。无范围时先看少量并标明覆盖范围。只总结已看到的文字和媒体。

## 点赞（第一条已实测）

1. 定位指定动态。“第一条”按顶部第一条判断；当前已滚动则先回顶部。
2. 记录作者或内容锚点，点击该动态的“··”菜单。
3. 显示“赞”时点击一次；显示“取消赞”或已确认自己赞过时结束。
4. 确认出现自己的点赞标识，或菜单变为“取消赞”；其他人的点赞不代表自己已赞。

## 发布

输入：准确文案、可选媒体、用户指定可见范围。图片加文案已实测；视频和纯文字待实测。

1. 媒体不在手机时先读 [媒体传输](../references/media.md)。
2. 带媒体：点右上相机，选择手机相册中的目标媒体并完成选择。纯文字：仅在工具支持长按时尝试相机长按入口；没有可靠入口就报告阻塞，不擅自添加图片。
3. 按 [输入](../references/input.md) 填写文案，核对编辑页同时存在完整文案和正确媒体。打开相册预览不等于已经选中。
4. 核对可见范围：指定时按要求设置，未指定则沿用当前设置并在结果中说明，不擅自改为公开。页面未显示时进入相关设置确认再返回。
5. 已要求发表时提交一次。超时或无反馈先检查页面和新动态，不直接重试提交。
6. 在朋友圈确认新动态同时显示目标文案和媒体。仍在上传或结果不明确时报告未确认。

漏文案或媒体时先报告差异并确认是否已发布；不自动重发或删除。用户要求重发时先重建完整草稿再提交，删除旧动态需要用户明确指示。
