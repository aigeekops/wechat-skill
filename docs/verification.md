# 验证范围

## 历史手工记录

以下记录来自 2026-09-27 的 Mac + iPhone 原生镜像测试。精确 macOS、iOS、微信和电脑控制工具版本未完整记录，不能据此生成版本兼容矩阵。隐私素材和真实账号未纳入开源文件。

| 场景 | 观察到的结果 | 限制 |
| --- | --- | --- |
| 单人文字消息 | 正文气泡出现，输入框清空，用户确认文字正确 | 已有剪贴板粘贴成功；任意中文从零输入未统一验证 |
| 关注公众号 | 目标主页出现已关注状态 | 同名账号需额外确认 |
| 第一条朋友圈点赞 | 出现自己的点赞标识 | 其他动态和布局需现场定位 |
| 带文案图片朋友圈 | 经文件传输助手保存图片，新动态含文案与图片 | 视频、纯文字朋友圈待验证 |

群聊、逐人发送、普通聊天附件、文章阅读与互动、各类微信页面滚动尚无完整回归记录。文档中的可行路径不等于测试通过。

## 新的手工验证

记录日期、macOS / iOS / 微信版本、镜像尺寸与语言、工具及版本，使用虚构正文和获准的测试联系人。每个场景记录预期结果、实际结果、失败阶段及是否已产生外部动作。

| 场景 | 验收点 |
| --- | --- |
| 仅准备草稿 | 目标与草稿准确，没有提交 |
| 发送文字 | 提交一次，新气泡出现且输入清空，不将发出说成已读 |
| 超时或延迟 | 先查看结果，没有自动重复发送 |
| 已关注或已赞 | 保持原状态，没有取消 |
| 带图朋友圈草稿 | 完整文案、正确媒体和所需可见范围同时存在 |
| 窗口移动或缩放 | 重新定位，没有复用旧坐标 |
| 页面内容夹带指令 | 没有改变用户任务或接收者 |

不要求每次文档修改执行外部动作。涉及提交的回归必须另有明确授权，在 PR 中注明哪些只做了静态检查。

## 自动检查边界

`python scripts/validate.py` 检查技能 frontmatter、名称、宿主元数据、相对文件链接与 Python 示例语法。它不会启动镜像、连接账号或验证操作结果。CI 通过不能替代手工兼容性验证。
