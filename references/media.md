# 电脑媒体进入手机相册

输入：媒体文件、后续微信操作。媒体已在手机且可确认时跳过传输。

既有路线：微信文件传输助手 → 保存到手机 → 微信选择相册。图片到朋友圈有实测记录；视频保存与格式兼容仍需现场验证。

1. 确认电脑文件可用且预览正确，不把路径字符串当作媒体粘贴。
2. 微信搜索“文件传输”，选择“文件传输助手”并核对会话标题。中文输入困难可尝试拼音搜索，仍须核对候选。
3. 使用当前工具支持的媒体粘贴、文件选择或传输入口放入文件。出现发送预览时核对目标媒体，再发送一次。图片剪贴板路线曾成功，视频不能假设同样支持。
4. 聊天出现目标媒体后打开预览，使用保存入口；没有按钮时，仅在工具支持长按时尝试长按菜单。
5. 到手机相册或微信相册选择器核对媒体已出现。聊天缩略图不代表已保存，不仅凭“最新一项”判断身份。
6. 回到应用手册继续填写文案和提交。传输成功不等于发布成功。

缺少传输能力时报告阻塞，不重复发送同一文件。传输到文件传输助手不授权将其发送给其他联系人。
