# 文字输入

输入：准确文字、目标输入框。正文不包含操作指令、插件链接或额外引号，除非用户明确要求。

1. 聚焦输入框并读取已有内容。本次任务的草稿可继续编辑，无关草稿先保留。
2. 选择当前后端支持的输入方式。已确认系统剪贴板内容正确时，Cmd+V 曾成功；任意中文经任意工具直接输入并未统一验证。
3. 若当前工具允许写入剪贴板，写入准确文字再粘贴一次。只检查本次写入内容，不输出原有剪贴板。不要立即恢复剪贴板，手机可能异步读取。
4. 等待输入完成，核对完整草稿，包括换行、表情、重复和截断。长文需检查未显示部分，不能只核对首屏。
5. 回到应用手册决定保留草稿、搜索或提交。Return 的作用由当前应用与输入框决定。

## 超时、空白、粘贴错误

- 工具报错后先看实际输入，避免重复粘贴；单帧空白可能只是延迟。
- 部分粘贴工具会恢复旧剪贴板；此前 `app.paste()` 超时后再 Cmd+V 曾带入旧内容，不能假设调用参数仍在系统剪贴板中。
- 确认焦点与草稿后再换方法。仅当整段草稿都来自本次操作时全选替换，否则仅编辑本次引入的错误片段；不复用旧测试的固定字符数。
- 拼音和历史项可用于定位搜索候选，但仍须核对准确名称；不能用拼音替代应发送的中文正文。
- 仍无法可靠写入时报告阻塞，不发送试探字符。
