# Mac + iPhone 连接

1. 使用现有电脑控制工具连接 Apple iPhone 镜像。CUA 入口为 `cua.getApp("com.apple.ScreenContinuity")`，后续方法遵循本次工具返回的文档。
2. 读取窗口状态；AX 缺少手机内部控件时读取窗口截图。确认镜像连接且能看到手机应用。锁屏、认证或连接提示按实际界面处理，需要用户完成的步骤明确说明。
3. 从当前页继续，必要时回主屏，通过图标或系统搜索打开微信。不为每个小动作重新连接。
4. 坐标来自当前窗口。截图像素、窗口局部坐标与桌面点坐标可能不同，按工具约定转换；窗口移动或尺寸变化后重新定位。

默认使用当前可用的电脑控制工具。Phone Harness 是可选方式，只有环境已提供且允许使用时才调用，无需为普通点击安装它。导入或运行前设置 `PHONE_HARNESS_TELEMETRY=0`；路径以实际安装位置为准，不依赖历史临时目录。滚动适配见 [滚动](scroll.md)。

## 边界与阻塞

- 仅支持 Mac + iPhone 原生镜像。请求其他平台时说明当前技能范围，不套用本手册。
- 工具拒绝访问时不要反复调用同一接口或换路径绕过拒绝；报告工具给出的原因。用户口头同意不等于系统权限已生效。
- 镜像会话需要 iPhone 保持锁定；初始化要求解锁认证时按提示完成，再恢复镜像连接。设备条件与可用地区以 [Apple 官方说明](https://support.apple.com/en-us/120421) 为准。
- 镜像操作不构成应用无法识别自动化或账号不受限的保证。
