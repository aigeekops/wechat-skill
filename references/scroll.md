# 微信页面滚动

输入：目标区域、方向、条数或结束条件。用结果描述方向，例如“看更早的聊天”“看文章下方”，避免混淆手指与内容移动方向。

1. 确认目标是聊天列表、聊天内容、文章还是朋友圈，先处理遮挡目标的弹层。
2. 使用当前工具支持的滚动动作一次，落点置于目标区域内部。
3. 比较消息、时间、段落或动态作者等锚点，确认方向和位置确实改变。
4. 按范围继续；内容不变时检查是否到底、遮挡、落点错误或手势不兼容。拖动可能被识别成点击，不盲目扩大距离。

## 可选：Phone Harness

只有环境已提供且允许使用时才调用滚动封装。导入前设置 `PHONE_HARNESS_TELEMETRY=0`，按当前安装版本核对 API。获取最新窗口位置，将落点选在实际可滚动区域，不复用其他页面的比例或位移。

已检查版本会验证落点命中镜像窗口，移动实际指针，发送 `mouseMoved` 更新命中区域，再发送像素滚动并恢复指针。可能短暂置前镜像窗口，不能假设完全不影响前台。

这个底层方法有其他镜像场景的测试记录，尚未完成微信各类页面的滚动验证，不能据此标记微信滚动已支持。来源与审阅版本见 [第三方说明](../THIRD_PARTY.md)。
